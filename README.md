## 🛠️ 快速开始

```bash
# 克隆仓库
git clone https://github.com/YR4399/wx-mini-scripts.git

# 将脚本放入呆呆面板
cp code/*.py /app/Dumb-Panel/scripts/code/

# 配置环境变量
export wx_server_url='http://172.17.0.3:8787'
export wx_auth='your_api_key'
export wx_opinion='openid1&openid2'
```
